# speedtest

Скрипт-замерятель скорости интернета с вашего компьютера: делает 10 последовательных запросов к заданному адресу (например, тяжёлой картинке), дожидается ответа на каждый, считает среднее время запроса, объём скачанных данных и печатает скорость в МБ/с.

Только стандартная библиотека. Python 3.9+.

## Запуск

```bash
python speedtest.py https://example.com/heavy-image.jpg
```

Опции:

| Опция | По умолчанию | Что делает |
|---|---|---|
| `--runs N` | 10 | число последовательных запросов |
| `--timeout SEC` | 30 | таймаут одного запроса |
| `--no-cache-bust` | выкл. | не добавлять к URL уникальный параметр против кэширования |
| `--json` | выкл. | печатать итог одной строкой JSON вместо отчёта; прогресс по запросам не печатается |

Пример вывода:

```
[ 1/10]    0.412 с       2.35 МБ
[ 2/10]    0.398 с       2.35 МБ
...
[10/10]    0.401 с       2.35 МБ

Запросов:            10
Среднее время:       0.404 с
Скачано всего:       23.50 МБ (23500000 байт)
Скорость:            58.17 МБ/с (465.3 Мбит/с)
```

С `--json` вывод такой (одна строка):

```json
{"runs": 10, "average_seconds": 0.404, "total_bytes": 23500000, "megabytes_per_second": 58.17, "megabits_per_second": 465.3}
```

Код возврата: `0` — успех, `1` — сетевая ошибка или ответ сервера с ошибкой, `2` — неверные аргументы. Ошибки всегда идут в stderr, в том числе при `--json`.

## Как считается

- Запросы идут строго последовательно; время каждого — от начала запроса до полного чтения тела, включая установку соединения и TLS.
- Скорость — суммарный объём за суммарное время всех запросов (а не среднее из скоростей отдельных запросов).
- МБ — десятичный мегабайт (1 000 000 байт), как в тарифах провайдеров; рядом печатается значение в Мбит/с.
- К URL по умолчанию добавляется уникальный параметр `_speedtest=<метка>`, чтобы CDN или браузерный прокси не отдали ответ из кэша. Если сервер на лишние параметры отвечает ошибкой — `--no-cache-bust`.
